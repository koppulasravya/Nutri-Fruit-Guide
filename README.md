
🍎 Nutri-Fruit-Guide
A dynamic and attractive web application built with Flask that helps users explore fruit details based on colors.  
* Features
Color Selection: Choose from various colors like Red, Green, Yellow, etc.  
Fruit Catalog: Displays specific fruits associated with the selected color.  
Detailed Insights: Provides the Scientific Name, Health Benefits, and Vitamin Types for each fruit.  
Tree-Style UI: Information is displayed in an attractive, branching layout for better user experience.  
*Tech Stack
Backend: Python (Flask)  
Frontend: HTML5, CSS3
